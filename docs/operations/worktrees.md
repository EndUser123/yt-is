# yt-is worktree inventory

PR 5 of `P:/docs/worktree-lifecycle-design.md`. Generated doc for the worktree lifecycle state.

## Policy

The package's worktree lifecycle policy lives at `P:/packages/yt-is/worktree-policy.toml`. Loaded by `cc-skills-sdlc/skills/go/scripts/worktree_lifecycle.py::load_policy`. Manual edits to that file are safe — only the values are read.

## Current inventory

Generated by `handoff_sync.sync`. The worktree list lives in this file and is regenerated by running:

```powershell
python P:/packages/.claude-marketplace/plugins/cc-skills-sdlc/skills/go/scripts/handoff_sync.py sync `
    --repo P:/packages/yt-is `
    --handoff P:/packages/yt-is/HANDOFF.md
```

(PR 4's CLI surface — `worktree_cleanup.py list` — is the read-only counterpart.)

## Hook

`P:/packages/yt-is/.claude/hooks/worktree_policy_PreToolUse.py` blocks `git worktree` Bash invocations by default. Escape hatch: `GO_WORKTREE_SAFETY_BYPASS=1`. The hook is the user-facing enforcement layer; `worktree_cleanup.py` is the policy-validated CLI it points at.

## Backup tags

`backup/<branch>-<timestamp>` format. Created automatically by `safe_delete_branch` when `auto_tag=True`. To list current backups:

```powershell
git -C P:/packages/yt-is tag -l "backup/*"
```

Recovery from a backup tag:

```powershell
git -C P:/packages/yt-is checkout backup/<branch>-<timestamp> -- -m
```
